One sentence, at most 200 characters, pitching a bizarre startup idea that sounds like a joke until you see the customers and the money. This entry sells engraved plaques that name potholes after your ex: heartbroken dumpers pay $25 each for revenge, and cities get their roads fixed with that revenge money.

> We sell engraved plaques naming potholes after your ex, because heartbroken dumpers pay $25 each and cities get their roads fixed with revenge money.

## Run it

```sh
python3 main.py
```

This writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, after validating it at runtime: exactly one sentence, 1–200 characters, not only whitespace.
